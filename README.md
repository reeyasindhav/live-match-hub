Problem Statement: 

Sports fans often rely on multiple websites and apps to access live scores, match updates, player statistics, and expert analysis, resulting in a fragmented and inefficient experience. There is a need for a unified platform that delivers real-time sports information, comprehensive statistics, and engaging match insights in a visually appealing and easy-to-navigate interface. Sportcast aims to solve this problem by providing live scores, detailed match analysis, player and team statistics, interactive match timelines, and personalised sports content in one centralised platform.
